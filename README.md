## English

**A Windows Android app launcher that makes Android apps feel like native Windows software.** Install APK files, create a separate desktop shortcut for each app, and run apps in independent windows. ApkStart also supports Start menu integration and two-way file synchronization between Windows and Android.

See the full [English project overview and setup guide](README.en.md).

## فارسی

**اجراکننده برنامه‌های اندروید در ویندوز با تجربه‌ای شبیه نرم‌افزارهای بومی دسکتاپ.** فایل‌های APK را نصب کنید، برای هر برنامه میان‌بر جداگانه بسازید و برنامه‌ها را در پنجره‌های مستقل اجرا کنید. ApkStart همچنین از اتصال به منوی Start و همگام‌سازی دوطرفه فایل‌ها میان ویندوز و اندروید پشتیبانی می‌کند.
